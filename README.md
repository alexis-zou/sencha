# Sencha

A web app designed to help young entrepreneurs streamline taking orders, managing inventory, and keeping track of total income and sales. Users can host collaborative events with live, real-time syncing of orders between devices, save menus across events, and notify customers via text when their order is completed. 

### About The Project
This app was inspired by my own and my friends' experiences running matcha sale fundraisers, farmers' markets, and concession stands. We faced challenges with managing incoming orders (relying primarily on sticky notes), tracking profits, and running out of stock when demand was still high. Sencha was conceptualized to address these issues and help future young entrepreneurs run their own businesses with improved ease and efficiency.  

Tech Stack: Built with Next.js, React, HTML/CSS, Supabase.

### UI Features

- Host upcoming markets and events with customized time, dates, menu items, and price details
- Take incoming orders, edit incomplete orders, and update inventory when orders are completed
- Alert customers with a custom text notification when their orders are ready
- Collaborate with other team members on events with real-time event and order syncing
- Track income across events
- Export PDF event summaries post-event with customer analytics, income, and best menu item sellers 

### Installation

1. `git clone https://github.com/alexis-zou/sencha.git`
2. `npm install`
3. Create a local environment and add Supabase credentials
4. `npm run dev`
5. Open on your local browser
